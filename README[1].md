# Crislio Store — catálogo automático

Esta versión NO guarda las imágenes en el ZIP. La página consulta la tienda diaria de Fortnite al abrirse y carga sus imágenes reales desde la API, por lo que el catálogo puede cambiar automáticamente.

Para publicar en Render:
1. Sube `index.html` a un repositorio de GitHub.
2. Crea un Static Site en Render.
3. Conecta el repositorio.
4. Build command: vacío.
5. Publish directory: `.`

Antes de usarla como tienda real, cambia el número de WhatsApp/Yape y revisa las condiciones de uso de las imágenes/datos de terceros.
